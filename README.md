\# U.S. Alcohol Consumption Trends (1977–2023)



An interactive data visualization dashboard exploring 47 years of U.S. alcohol consumption data across all 50 states.



\## 🔗 Live Dashboard

&nbsp;https://alcohol-dashboard-301168671061.us-central1.run.app



\## Overview

This project analyzes the NIAAA Apparent Per Capita Alcohol Consumption dataset (1977–2023) using the QUEST visual analytics framework. The dashboard features 5 analytical chapters covering national trends, state-level geography, beverage composition shifts, COVID-19 impact, and regional comparisons.



\## Key Findings

\- U.S. consumption peaked in 1981 (2.76 gal/capita) and hit a 30-year low in 1997

\- Spirits overtook beer in 2022 for the first time in recorded history

\- The geographic hierarchy (NH highest, UT lowest) has held for nearly 5 decades

\- COVID-19 permanently accelerated the spirits preference shift
